## Introduction

Guance Windows SDK provides real user monitoring, logging, and trace correlation for Windows desktop applications. It supports .NET/C# applications targeting .NET 6 or .NET 8 and native C/C++ applications on Windows 10 and later. Native runtime assets are available for win-x64, win-x86, and win-arm64, with distribution through NuGet and vcpkg.
